      Modelli di ripiego (in ordine)
        Quando il modello scelto è occupato, ha raggiunto il limite o la connessione cade, Mia prova questi in ordine (al massimo 8). Un modello che ha appena raggiunto il limite viene saltato per qualche minuto. Con le frecce cambi l'ordine; i modelli senza chiave vengono saltati. Questo elenco è separato dai preferiti del cambio rapido.
        Velocità misurate dei modelli
          Misurate sulle tue risposte (media delle ultime). «Parole al secondo» e «1° testo»: i modelli più alti nell'elenco sono i più veloci. Dove manca il «1° testo» (senza streaming) la risposta arriva tutta insieme alla fine.

          Modalità agente e strumenti

          Usa il token GitHub qui sopra. Per crearne uno fine-grained: github.com/settings/personal-access-tokens.

          Mia non scrive mai sul branch principale: crea da sola il branch di lavoro e ci mette le modifiche. Tu controlli su GitHub e unisci con una pull request. Se il branch non ha modifiche proprie, viene riallineato al principale da solo.

          Il repository si sceglie nella sezione GitHub qui sopra. Con questa opzione Mia non legge, non modifica e non crea altri repository, anche se il token può accedervi. Se non è selezionato nessun repository, gli strumenti GitHub restano bloccati.

          Creazione di immaginiprovider e modello

          Usano le chiavi dei provider NVIDIA e Google Gemini già inserite. NVIDIA dà crediti gratuiti di prova che si esauriscono (e può usare i testi inviati per migliorare i suoi modelli: niente dati sensibili); il piano gratuito di Gemini può non includere le immagini. In «Automatica», se un servizio fallisce passa al successivo; Pollinations è gratuito e senza chiave, ma è un progetto di comunità senza garanzie, e la descrizione viene inviata a quel servizio. Vale anche per «disegna…» nella chat.

          Ricerca webprovider e chiave

          Con «Google, tramite Gemini» non serve altro che la chiave Gemini già inserita (la quota gratuita delle ricerche può essere limitata o non disponibile sul tuo piano). «DuckDuckGo» non ha chiave né API ufficiale: legge la sua pagina web, quindi può smettere di funzionare o chiedere una verifica anti-robot (nel browser è bloccato, nell'app Android dovrebbe funzionare). Per Tavily, Serper ed Exa serve una chiave del servizio: i limiti gratuiti li decide ciascuno e cambiano nel tempo, controllali sul sito. La domanda viene inviata al servizio scelto.

          Quanti giri di strumenti può fare Mia prima di fermarsi (3-100). Più alto = lavori più lunghi, ma più richieste al modello e più crediti gratuiti consumati: oltre 40 conviene solo con un modello forte e per lavori semplici e ripetitivi.

          Connettori (MCP)servizi esterni
          Connettori (MCP)

          Collega servizi esterni che offrono un server MCP «HTTP» (indirizzo https://…). Mia ne scopre gli strumenti e li usa; ogni azione che non è di sola lettura chiede conferma. Puoi anche collegare il tuo computer con «Mia Bridge» (vedi README). Nel browser il server deve accettare richieste CORS; nell'APK Android di solito non serve.

          Le azioni che modificano qualcosa (creare, scrivere, eliminare, commentare) chiedono sempre il tuo permesso. Le note sono salvate sul telefono.

          «Leggi pagina web» prova l'indirizzo direttamente; se il sito lo blocca passa dal servizio r.jina.ai, che vede l'indirizzo richiesto.

          Sincronizzazione e dati
          Sincronizzazione tra dispositivi Usa un repository GitHub privato (se è pubblico Mia rifiuta di inviare). Serve il token GitHub di «Modalità agente» con accesso a quel repository e «Contents» in lettura e scrittura. Si sincronizzano chat, testo dei PDF e Memoria; non chiavi, token, immagini e file allegati.

          Chiavi e conversazioni restano solo su questo dispositivo. Per portare le chat su un altro dispositivo: «Esporta chat» → salva il file su Drive → sull'altro dispositivo «Importa chat» e scegli il file da Drive. Le chiavi non vengono esportate. Chiudi per salvare.

            Repository di questa chat

              Ogni chat ha il suo repository: una chat nuova parte senza. In modalità agente Mia lavora solo su quello (e sul suo branch di lavoro).

              Consumo di token

              I token sono quelli dichiarati dal servizio; dove non li dichiara sono una stima (≈, circa 3,6 caratteri per token; le immagini contano circa 800). Il costo si calcola solo per i modelli per cui scrivi i prezzi, in dollari per milione di token (guarda il listino del provider: non li conosco con certezza). L'IVA non è inclusa. I modelli gratuiti restano senza costo.
