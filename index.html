    Impostazioni

      Crea un token «fine-grained» su github.com/settings/personal-access-tokens: scegli solo i repository che vuoi far gestire a Mia e, in Repository permissions, dai Contents, Issues, Pull requests, Actions e Metadata in lettura/scrittura. Per creare nuovi repository serve un token «classic» con il permesso repo. Il token resta solo su questo dispositivo.

      Per «genera immagine» usa la chiave del provider Google Gemini. Il piano gratuito può non includere le immagini: se dà errore, controlla il nome del modello o i limiti del tuo account.

      Connettori (MCP)

      Collega servizi esterni che offrono un server MCP «HTTP» (indirizzo https://…). Mia ne scopre gli strumenti e li usa; ogni azione che non è di sola lettura chiede conferma. Nel browser il server deve accettare richieste CORS; nell'APK Android di solito non serve.

      Le azioni che modificano qualcosa (creare, scrivere, eliminare, commentare) chiedono sempre il tuo permesso. Le note sono salvate sul telefono.

      «Leggi pagina web» prova l'indirizzo direttamente; se il sito lo blocca passa dal servizio r.jina.ai, che vede l'indirizzo richiesto.

      Chiavi e conversazioni restano solo su questo dispositivo.
