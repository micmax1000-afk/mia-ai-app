    Impostazioni

      Usa il token GitHub qui sopra. Per crearne uno fine-grained: github.com/settings/personal-access-tokens.

      Per «genera immagine» usa la chiave del provider Google Gemini. Il piano gratuito può non includere le immagini: se dà errore, controlla il nome del modello o i limiti del tuo account.

      Con «Google, tramite Gemini» non serve altro che la chiave Gemini già inserita (la quota gratuita delle ricerche può essere limitata o non disponibile sul tuo piano). «DuckDuckGo» non ha chiave né API ufficiale: legge la sua pagina web, quindi può smettere di funzionare o chiedere una verifica anti-robot (nel browser è bloccato, nell'app Android dovrebbe funzionare). Per Tavily, Serper ed Exa serve una chiave del servizio: i limiti gratuiti li decide ciascuno e cambiano nel tempo, controllali sul sito. La domanda viene inviata al servizio scelto.

      Quanti giri di strumenti può fare Mia prima di fermarsi (3-40). Più alto = lavori più lunghi, ma più richieste al modello.

      Connettori (MCP)

      Collega servizi esterni che offrono un server MCP «HTTP» (indirizzo https://…). Mia ne scopre gli strumenti e li usa; ogni azione che non è di sola lettura chiede conferma. Puoi anche collegare il tuo computer con «Mia Bridge» (vedi README). Nel browser il server deve accettare richieste CORS; nell'APK Android di solito non serve.

      Le azioni che modificano qualcosa (creare, scrivere, eliminare, commentare) chiedono sempre il tuo permesso. Le note sono salvate sul telefono.

      «Leggi pagina web» prova l'indirizzo direttamente; se il sito lo blocca passa dal servizio r.jina.ai, che vede l'indirizzo richiesto.

      Chiavi e conversazioni restano solo su questo dispositivo. Chiudi per salvare.
